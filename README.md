# イコール・クエスト 〜表計算で世界を救うRPG〜

Excelの基本を「町の人の悩みを解決する」形で学ぶ、ドラクエ風の学習RPG（Webアプリ）。

## 起動

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に本番ビルド
npm run check    # 依頼・謎がクリアできるか、戦闘の問題・マップに誤りがないかを自動チェック
```

## 操作

| 操作 | キー |
|---|---|
| 移動 | 矢印キー / WASD（Shift を押しながらで走る） |
| 話す・決定 | Enter / Space / Z |
| メニュー・キャンセル | Esc / X |
| スマホ | 画面下の十字ボタン・A（決定）/B（メニュー）ボタン |

### スマホで遊ぶ

- **縦持ちで 画面いっぱい**：フィールドは縦長に表示し、下に十字ボタンとA/Bボタンを置く。戦闘中はボタンをしまい、コマンドや答えをタップで選ぶ
- **全画面**：Android の Chrome は「はじめから／つづきから」を押すと全画面になる。iPhone は Safari の共有ボタン →「ホーム画面に追加」で、ブラウザの枠なしで起動できる（`public/manifest.webmanifest`）
- **依頼は「知識を答える」ステップ式**：スマホでは セルを正確に選んだり ドラッグしたりする操作はさせず、表は見るだけ（セルをタップすると数式がのぞける）。「どの関数を使うか」「この操作で何が起きるか」を選択肢で答え、数式は 正解の部品にひっかけを混ぜたボタンから組み立てる。`$` は F4 ボタンで付ける
- 数式は 入れたあと自動でオートフィルされ、`$` を付け忘れると コピー先のセルが赤くなって「=B3*F2 → 0」のように ずれが見える
- 戦闘の数式問題も 同じボタンで組み立てる
- 入力方式（ボタン／キーボード）は メニューの「にゅうりょく」で切り替えられる。キーボードにすると PC と同じミニExcelで解く

依頼ごとのステップは `src/data/guides.ts`。全ステップを正解すると 元の依頼の判定（`check`）も通るように作り、`npm run check` で確かめている。

## 収録内容（第1章〜最終章）

- **プロローグ**：現代のオフィス → 深夜に #REF! の光に包まれ転生
- **はじまりの森**：目覚めるとセルイムが出現。戦い方を覚えるチュートリアル戦
- **ワールドマップ**：町と町の間を歩いて移動。草原・森ではモンスターとランダムに戦う
- **建物の中**：宿屋（HP回復）・教会（セーブ）・道具屋・武器屋・防具屋・民家に入れる。店主とはカウンター越しに話せる
- **装備**：ぶき（攻撃力）・よろい（守備力）・たて・かぶと（回答時間の延長、一発決裁の出やすさ）。メニューの「そうび」で付け替え
- **ボスステージ**：村の北の「散らかりの洞窟」。歩くと敵が出現し、3つの石版の扉をExcelの謎解き（オートフィル／コピー＆貼り付け／修正＋太字）で開けて進む。宝箱と回復の泉があり、最奥に散らかりセルイム
- **戦闘**：残り時間バーが緑のうちに正解すると「即答ボーナス」（ダメージ1.25倍）。大ダメージの「一発決裁」は確率（基本5%、ブルーライトメガネで10%）
- **問題の自動生成**：戦闘の問題は、セル番地・連番・計算・関数・数式入力などの多くが出題のたびに数値の変わる自動生成（`src/data/questionGen.ts`）。答えの丸暗記では通用しない
- **ボスステージ（町）**：カルキュレの北の「計算の塔」。1階→2階→屋上と階段で上り、各階の扉を 掛け算の数式／SUM／AVERAGE・MAX・COUNT の謎解きで開ける。屋上に手計算ゴーレム
- **ボス戦**：こちらの攻撃（問題に正解で攻撃）のあと、ボスが問題を出して攻撃してくる。正解するとダメージが減り、5%の確率でゼロ。ボスを倒すとダンジョンの外へ自動で脱出（ボスは仲間にならない）
- **イベント演出**：村に入ると長老が、町に入ると町長が走ってきて話し、終わると家へ帰っていく

- **はじまりの村 セルノ**：入力・修正(F2)・コピペ・元に戻す・オートフィル・太字 → ボス「散らかりセルイム」
- **計算の町 カルキュレ**：四則演算・SUM・AVERAGE・MAX/MIN・COUNT・集計表 → ボス「手計算ゴーレム」
- **（第2章）鏡の町 サンショウ**：相対参照・絶対参照($)・F4キー・構成比・複合参照（九九の表）・ROUND → ボス「ズレズレ・ミラージュ」
  - 行き方：ゴーレムを倒すと海峡の橋が完成し、カルキュレの東門からワールドマップの東の大地へ渡れる
  - ボスステージ：町の北の「鏡の神殿」。前殿の2つの扉（税込計算／割合）と、大鏡の間の扉（掛け算の表）を、$を使った1つの数式のコピーで開ける
  - 戦闘：新しい敵カガミン・ズレドリ。数式問題の一部は「⇩ のセルにもコピーして確かめる」形式で、$ を付け忘れると参照がずれて不正解になる
  - ミニExcel・戦闘の数式入力とも、入力中に **F4**（Macは fn+F4）で $A$1 → A$1 → $A1 → A1 と切り替えられる
- **（第3章）条件の港町 イフポート**：比較演算子・IF・IF×計算・入れ子のIF・AND/OR・COUNTIF/SUMIF → ボス「幽霊船長モシナラバ」
  - 行き方：ミラージュを倒すとサンショウ南の峠の「鏡の霧」が晴れ、ワールドマップ南東の港町へ行ける
  - ボスステージ：桟橋に停泊する「幽霊船」。船倉の2つの扉（IFで仕分け／入れ子のIFで3段階）と、船長室の扉（COUNTIF・SUMIF）を解いて進む
  - 戦闘：新しい敵イフクラゲ・ブンキガニ。IF の数式問題は答えが文字（"大漁" など）になり、コピー先でもう片方の分岐も確かめる
  - 日本語入力で入りがちな「“ ”」は " として扱う。「≧ ≦ ≠」を使うと >= <= <> で書くよう注意が出る

- **（第4章）検索の城下町 ルックアップ**：VLOOKUP・列番号と範囲の固定・近似一致（TRUE）・IFERROR・XLOOKUP（左の列を取り出す）・XLOOKUP の「見つからないとき」 → ボス「迷宮書庫の主 ミツカラーヌ」
  - 行き方：モシナラバを倒すと 南の海の定期船が動き出す。イフポートの桟橋の船乗りに話すと渡れる（ルックアップの桟橋から いつでも戻れる）
- **（第5章）集計の王都 ピボリア**：COUNTIFS・SUMIFS・比べる条件（">=1000"）・AVERAGEIF / MAXIFS・集計表（見出しのセルを条件に）・クロス集計（$E2 と F$1）、ピボットテーブルの考え方 → ボス「散乱帳簿の王 バラバラン」
  - 行き方：ミツカラーヌを倒すと 東の街道が通れるようになる。ルックアップ東端の馬車の御者に話すと向かえる（ピボリアの馬車から いつでも戻れる）
- **（第6章）文字の宿場町 テキストリア**：& で つなぐ・LEFT / RIGHT・MID・LEN（IF と組み合わせ）・TRIM / SUBSTITUTE・FIND（LEFT / RIGHT / LEN と組み合わせ） → ボス「文字化けの怪 モジバケーラ」
  - 行き方：バラバランを倒すと 西の宿場町への馬車が動く。ピボリア西端の御者に話すと向かえる（テキストリアの馬車から いつでも戻れる）
- **（第7章）暦の里 コヨミノ**：日付の足し算・引き算（今日のセルを $ で固定）・YEAR / MONTH / DAY・WEEKDAY と IF・EDATE / EOMONTH・DATEDIF → ボス「刻を喰らう者 シメキリス」
  - 行き方：モジバケーラを倒すと 東の里への馬車が動く。テキストリア東端の御者に話すと向かえる（コヨミノの馬車から いつでも戻れる）
  - 日付は「2026/10/1」のように 年/月/日 で入力・表示する
- **（最終章）最果ての砦 ホープ**：エラーの読み方と直し方（#DIV/0! と IFERROR・#VALUE!・#NAME?・#REF! と $ の固定）・SUMIFS と IF の組み合わせ・数値と文字の連結 → 魔王城で 総まとめの謎を解き、ラスボス「魔王レフエラー」
  - 行き方：シメキリスを倒すと 北の砦への馬車が動く。コヨミノ東端の御者に話すと向かえる（ホープの馬車から いつでも戻れる）
  - 魔王を倒すと エピローグ（元のオフィスで #REF! を直す）→ 最終章のエンディング
  - ボスステージ：城の「大書庫」。棚の扉（VLOOKUP）・著者の扉（XLOOKUP で左の列）と、禁書の間の封印の扉（IFERROR＋VLOOKUP のコピー）を解いて進む
  - 戦闘：新しい敵ナイナイ・シオリムシ。数式問題では VLOOKUP・XLOOKUP・IFERROR を組み立てる
  - 数式の TRUE / FALSE は Excel と同じく そのまま書ける（`=VLOOKUP(…,FALSE)`）

町の悩み（クエスト）をすべて解決すると北の結界が解け、ボス戦（復習クイズ＋数式入力）に挑めます。

### ふくしゅうの書（復習モード・達成率）

タイトル画面の「ふくしゅう」、またはゲーム中のメニューの「ふくしゅう」から開けます。戦闘ではなく、時間制限なしで 1問ずつ解き、毎回 答えと解説が出ます。

- **苦手克服コース**：まちがえた問題と その類題（同じ敵の別の問題・数値を変えた自動生成問題）を中心に 10問
- **全章まとめコース**：開放した章から まんべんなく 10問（タイトルからは 全章）
- **章ごとの復習**：選んだ章の問題を 5問。ゲーム中は 章ごとの達成率（依頼・謎・ボス・宝箱）も表示
- 結果画面から「まちがえた問題の類題を解く」「同じコースをもう一度」ができる
- まちがえた問題は 戦闘・復習の両方で記録（セーブとは別に端末へ保存）、正解すると消える
- 章の定義は `src/data/chapters.ts`、画面は `src/components/Study.tsx`

### クエストを追加する

`src/data/quests.ts` の `QUESTS` に1件追加し、`src/data/maps.ts` のNPCに `kind: 'quest', questId` を設定するだけです。
判定は `check(ctx)` で行い、未達成なら理由（プレイヤーへのフィードバック）を、達成なら `null` を返します。
`expectNum(ctx, 'B12', 13880, 'SUM')` のように「値」と「使うべき関数」を同時にチェックできます。

### 開発用ショートカット

- `/?quest=calc_sum` … 指定クエストを直接開く
- `/?boss=golem` … 指定ボスと直接戦う（第2章は `mirage`、第3章は `captain`、第4章は `mitsukaranu`、第5章は `barabaran`、第6章は `mojibake`、第7章は `shimekiris`、最終章は `refera`）
- `/?prologue` … プロローグ（転生前のオフィス）から始める
- `/?at=world,13,17` … 指定マップの指定座標から始める（例：`celuno_inn,6,7`、`sansho,1,13`、`temple1,11,14`、`ifport,16,1`、`ship1,10,12`、`lookup,16,23`、`library1,10,12`、`pivoria,16,26`、`treasury1,10,12`、`textria,16,25`、`print1,10,12`、`koyomi,16,25`、`clock1,10,12`、`hope,16,25`、`castle1,10,12`）
- `/?study` … ふくしゅうの書（タイトルから開いたときと同じ）
- `/?epilogue` … エピローグ（魔王を倒した後のオフィス）を表示
- `/?ending=4` … 指定した章のエンディング画面を表示（`8` は最終章）
- `/?gallery` … 全キャラクターのドット絵を4方向で一覧表示
- `/?soundtest` … BGM・ジングル・効果音を 1つずつ 鳴らして 確かめる（音は `src/data/music.ts` の 楽譜と `src/game/sound.ts` で その場で 合成）
- `/?layout=phone` / `/?layout=wide` … スマホの縦画面レイアウト／横長レイアウトに固定する（ほかと組み合わせ可：`/?layout=phone&boss=golem`）
- `/?input=touch` / `/?input=keyboard` … 数式の入力方式を ボタン／キーボードに固定する

### キャラクターの見た目を変える

キャラは `src/data/maps.ts` の `CharSpec`（髪型・服装・帽子・ヒゲ・メガネ・色）の組み合わせで決まります。
パーツのドット絵は `src/game/spriteParts.ts` にあり、髪型 11種・服装 10種・帽子 9種などを用意しています。

```ts
{ hair: 'twin', hairColor: '#f0d890', eyes: 'big', blush: true,
  outfit: 'apron', color: '#6aa84a', hat: 'straw', hatColor: '#e8c870' }
```
